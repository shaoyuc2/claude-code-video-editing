# 用 Claude Code 剪影片 — 教學包

這一包教你用終端機剪 talking-head 影片（對鏡頭講話的自拍短片）：剪空拍、加速、上字幕、輸出成社群可發的成品。全程用 Claude Code 指揮，你自己一個剪輯軟體都不用開。

這套方法是實戰累積出來的：拿它做過商業影片、LinkedIn 個人影片（133 秒毛片剪到 101 秒、逐字對時字幕）、還有課程錄影的複習系統。包裡的參數和教訓都是真的付過學費的版本。

## 閱讀順序

1. `00-環境安裝.md` — 裝三個工具，並理解每個工具在管線裡幹嘛
2. `01-心法.md` — 這套方法的核心觀念，一頁，先讀再動手
3. `02-剪輯SOP.md` — 主文件。照著走一遍，每步都附可直接貼給 Claude 的指令
4. `03-踩坑清單.md` — 動手前掃一遍，卡住時回來查
5. `04-進階地圖.md` — 基本流程熟了之後，還能往哪裡走

## 開始前你需要

- 一台 Mac（Windows 也行，但安裝步驟要自己請 Claude 調整）
- Claude Code 訂閱（Pro 或 Max）
- 一支你自己拍的 30–60 秒測試影片：對著手機講一段話就行，講什麼都可以，記得自然一點、留幾個停頓（等下要剪它們）

## 用法建議

第一支影片照 `02-剪輯SOP.md` 一步一步走，跑通之後，讓 Claude 幫你把你自己的流程寫成一份你的 SOP。這套方法真正值錢的地方在於：每支影片跑同一份文件、踩了坑就回寫進文件，第三支影片開始你會明顯感覺到快。
